# ANGSD wiki — design previews

Static previews of how the [ANGSD wiki](https://github.com/ANGSD/angsd/wiki) could look
if it were published as a documentation site. Each file is self-contained.

Open them through htmlpreview (GitHub serves raw HTML as plain text, so it needs a proxy):

- **Material for MkDocs** — https://htmlpreview.github.io/?https://raw.githubusercontent.com/aalbrechtsen/angsd/wiki-preview/preview/angsd-mkdocs.html
- **Jekyll (just-the-docs)** — https://htmlpreview.github.io/?https://raw.githubusercontent.com/aalbrechtsen/angsd/wiki-preview/preview/angsd-jekyll.html
- **Three candidate looks** — https://htmlpreview.github.io/?https://raw.githubusercontent.com/aalbrechtsen/angsd/wiki-preview/preview/angsd-looks.html

Notes:

- These are previews, not working sites. Search, navigation links and the theme toggle do nothing.
- Each preview has two pages, switched with the buttons at the top.
- **To see rendered formulas, open the Genotype Likelihoods page** and scroll to Theory.
- The first two are real builds of all 86 wiki pages; the third is a set of hand-made
  style options.
